# TravelCanvas 小红书登录态补充扩展

该扩展是可选增强，只读取你主动发起的小红书搜索页中当前可见的结果卡。它不读取、导出或保存 Cookie、Token、密码、请求头或 Local Storage，也不会处理验证码或规避登录限制。

## Chrome 加载步骤

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`browser-extension/xhs-session`。
5. 打开 `http://127.0.0.1:3000/` 或 `http://localhost:3000/`。
6. 点击浏览器工具栏中的扩展图标，再点击“连接当前 TravelCanvas”。

## Edge 加载步骤

1. 打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录：`browser-extension/xhs-session`。
5. 返回本地 TravelCanvas，在扩展弹窗中主动连接当前标签页。

## 使用边界

- 每个目的地由用户点击一次“用已登录小红书补充”。
- 扩展依次查询景点与美食两组关键词，每组最多读取前 20 条可见结果，最多滚动 10 次并等待 20 秒。
- 只收集标题、摘要、公开作者名、链接、搜索顺序、页面可见点赞数和发布时间；缺失字段保持未知。
- 关闭已连接的 TravelCanvas 标签页后连接失效，下次使用需重新连接。
- 遇到验证码或登录失效时，扩展会停止。请在小红书页面人工处理后回到 TravelCanvas 重试。
- 页面结构变化导致无法识别结果卡时，不会猜测或发送空字段；TravelCanvas 仍可使用 Tavily 公开索引降级。
- 导入内容只保存在 TravelCanvas 当前约 30 分钟的内存方案中，不写入磁盘。

“登录态搜索热度代理”只综合当前搜索顺序、页面可见点赞和独立结果提及数，不是小红书官方榜单或完整站内热度。
